# Resources — design-system

> El **material crudo** que siembra este proyecto: marca, mockups, referencias visuales, guías previas — y también lo **verbal**: guías de tono, textos de campañas, glosarios, cómo habla hoy el producto. Lo cargás vos; el **Architect** lo procesa en definiciones (`.claude/CLAUDE.md`) y en las páginas del [`manual/`](../manual/), y el **Leader** las mantiene veraces tras cada commit. Es material histórico **inmutable**: no se edita para alinearlo con el canon vigente — las diferencias se registran en `map.md` (§ *Evolución*).

Tirá acá lo que tengas — crudo está bien.
